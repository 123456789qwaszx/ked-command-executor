// 줄 단위 재생 데모 — Yarn 문법의 작은 부분집합(MiniYarn이 읽는다).
//
// 명령은 그 자리에서 실행되지 않는다. YarnCommandBridge가 스펙으로 바꿔 YarnPlaybackDriver에 쌓고,
// 다음 대사 줄에 들어갈 때 VNLinePresentationFlow가 PlayCollected로 한 스텝에 재생한다.
// 그래서 줄 하나 = 스텝 하나이고, 앞 줄의 배경 명령은 다음 줄에 들어가는 순간 CleanupStep(Finish)로 정리된다.
//
// 줄마다 생명주기 상황 하나:
//   l01  줄 앞머리 명령 + 대기(24fr) — 끝날 때까지 Space(넘기기)는 거절된다(AdvanceGate: cps_node_busy)
//   l02  3초짜리 배경 이동 — 다 가기 전에 넘기면 다음 줄의 스텝 경계가 Finish로 끝낸다
//   l03  BGM(런 수명)은 줄을 넘어 흐른다 · 표정은 즉시 · 등장은 배경
//   l04  기다리는 이동(wait) — 여기서 R: 루트부터 다시 달려 l03까지 압축 시크
//   l05  box_hide — 쌓이지 않고 그 자리에서 실행되는 명령(Yarn이 끝날 때까지 기다린다)
//   l06  긴 pause 뒤에 명령이 하나 더 — 글자가 다 나온 뒤 pause가 끝나기 전에 Ctrl/Skip을 누르면
//        다음 줄이 앞 줄의 메인 루틴보다 먼저 시작된다(감사가 겹침 · 늦은 쓰기를 잡는다)
//   l07  감사 결과 보기
//   l08  #boxhide #auto — 대사창 없이 퇴장 연출, 끝나면 입력 없이 노드가 끝난다
//   끝   마지막 줄 뒤의 명령은 다음 줄이 없어 실행되지 않고 버려진다(경고)
